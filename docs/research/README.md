## Key Differentiators

1. The retailer changes nothing — call, speak, hang up
2. Reserved before travel — the never-wasted trip
3. Per-retailer vocabulary memory — confirmation-gated, per-retailer
4. Tamil-first with code-mixing — how the orders actually sound
5. Asked-vs-sold intelligence — sees demand that failed, not just what was placed

## Honest Positioning

> "We're not the first voice-ordering idea. We're the one that keeps the retailer's habit exactly as it is."
